자바 기초 12문제로 복습 — JAVA1 총정리

여기까지 오셨다면 자바의 기초 한 바퀴를 다 도신 것입니다. 이번 편은 새 개념 없이 JAVA1 시즌 전체를 점검합니다. 먼저 개념을 퀴즈로 확인하고, 그다음 직접 코드를 고쳐 실행하는 실습 문제를 풉니다.

한눈에 보는 시즌 지도

편핵심대표 함정
1출력(main·println)세미콜론·따옴표
2변수·자료형정수 나눗셈(10/3=3)
3형변환강제 변환 소수점 잘림
4입력(Scanner)nextInt 뒤 nextLine 엔터 삼킴
5연산자=(대입) vs ==(비교)
6조건문switch의 break 누락
7반복문무한루프(증감식 누락)

이 여섯 함정만 몸에 익혀도 기초는 충분합니다.

1단계 — 개념 빠른 점검

먼저 개념부터 OX·4지선다 12문제로 확인합니다. 정답은 눌러야 나옵니다.

미니 퀴즈

OX 4문제 + 4지선다 8문제

2단계 — 직접 풀어 보기 (컴파일러 문제)

이제 손으로 풉니다. 각 문제의 "컴파일러에서 직접 풀어 보기" 를 누르면 편집기가 열립니다. 코드를 고친 뒤 초록색 Run 을 눌러 결과를 확인하세요. 화면이 좁으면 크게 보기로 넓혀서 풀 수 있습니다. 정답은 각 문제 아래 "정답 보기" 를 누르면 나옵니다.

문제 1. 출력을 예측하고 실행해 확인하기

아래 두 줄의 출력을 먼저 종이에 적어 본 뒤, 실행해서 맞혀 보세요.

문제 1
public class Main {
  public static void main(String[] args) {
      System.out.println(10 / 3);
      System.out.println("25" + 5);
  }
}

📱 코드 실행(실습)은 태블릿·PC에서 이용할 수 있어요. 모바일에서는 위 코드를 눈으로 따라가며 확인하세요.

정답 보기

출력은 3 과 255 입니다. 정수끼리 나누면 소수점을 버려 3, 문자열에 +는 계산이 아니라 붙이기라 "255"가 됩니다.

문제 2. 소수 결과가 나오게 고치기

아래는 3만 출력됩니다. 결과가 3.3333... 으로 나오도록 한 줄을 고쳐 보세요.

문제 2
public class Main {
  public static void main(String[] args) {
      // 이 줄을 고쳐 3.3333... 이 나오게 하세요.
      System.out.println(10 / 3);
  }
}

📱 코드 실행(실습)은 태블릿·PC에서 이용할 수 있어요. 모바일에서는 위 코드를 눈으로 따라가며 확인하세요.

정답 보기

한쪽을 소수로 만들면 됩니다 → System.out.println(10.0 / 3); 정수끼리 나눌 때만 소수점이 버려집니다.

문제 3. 1부터 5까지 출력하도록 반복문 완성

지금은 1만 출력됩니다. 조건을 고쳐 1부터 5까지 한 줄씩 출력하세요.

문제 3
public class Main {
  public static void main(String[] args) {
      // 조건(i <= ?)을 고쳐 1~5를 출력하세요.
      for (int i = 1; i <= 1; i++) {
          System.out.println(i);
      }
  }
}

📱 코드 실행(실습)은 태블릿·PC에서 이용할 수 있어요. 모바일에서는 위 코드를 눈으로 따라가며 확인하세요.

정답 보기

조건을 i <= 5 로 바꿉니다. for (int i = 1; i <= 5; i++) 가 되면 1,2,3,4,5가 출력됩니다.

문제 4. 짝수만 출력하기

1부터 10까지 중 짝수만 출력하도록 if 조건을 추가하세요. (힌트: 나머지 연산자 %)

문제 4
public class Main {
  public static void main(String[] args) {
      for (int i = 1; i <= 10; i++) {
          // 여기에 짝수일 때만 출력하도록 조건을 넣으세요.
          System.out.println(i);
      }
  }
}

📱 코드 실행(실습)은 태블릿·PC에서 이용할 수 있어요. 모바일에서는 위 코드를 눈으로 따라가며 확인하세요.

정답 보기

i % 2 == 0 이면 짝수입니다. 반복문 안에 if (i % 2 == 0) System.out.println(i); 를 넣으면 2, 4, 6, 8, 10이 출력됩니다.

문제 5. 소수를 정수로 바꾸기(형변환)

d의 값 3.9를 정수로 바꿔 3을 출력하세요. (반올림이 아니라 소수점 버림)

문제 5
public class Main {
  public static void main(String[] args) {
      double d = 3.9;
      int n = 0;   // 이 줄을 고쳐 d를 정수로 바꾸세요.
      System.out.println(n);
  }
}

📱 코드 실행(실습)은 태블릿·PC에서 이용할 수 있어요. 모바일에서는 위 코드를 눈으로 따라가며 확인하세요.

정답 보기

int n = (int) d; 로 강제 형변환합니다. 결과는 반올림한 4가 아니라 소수점을 버린 3입니다.

마무리

이것만 기억하면 됩니다. 초보가 넘어지는 곳은 늘 비슷합니다 — 정수 나눗셈, 형변환 잘림, =와 ==, nextLine 엔터 삼킴, switch의 break, 무한루프. 이 여섯 함정만 몸에 익혀도 기초는 충분합니다.

퀴즈에서 대부분 맞고 실습 문제 다섯 개를 스스로 풀 수 있다면, 기초는 탄탄합니다. 막힌 문제는 해당 편을 다시 훑어보면 됩니다. 급할 것 없습니다.
