파이썬 시작하기 — 설치 없이 브라우저에서 첫 코드 실행(PRINT)

오늘 이 글이 끝나면, 여러분의 화면에는 이렇게 찍혀 있을 겁니다.

==============================
안녕하세요, 저는 홍길동입니다.
파이썬을 오늘 시작했습니다.
==============================

겨우 이거냐고요? 네, 겨우 이겁니다. 그런데 이 네 줄을 찍는 동안 파이썬 문법의 첫 규칙 세 개(대소문자, 따옴표, 주석)를 전부 만나게 됩니다. 그리고 하나 더 — 아무것도 설치하지 않습니다. 이 시리즈의 실습은 전부 글 속 실행창에서 바로 돌아갑니다.

준비물은 없습니다

파이썬은 문법이 짧고 읽기 쉬워서 첫 프로그래밍 언어로 가장 많이 선택되는 언어입니다. 원래는 컴퓨터에 설치해서 쓰지만, 이 시리즈에서는 본문 곳곳의 실행창에 있는 "컴파일러에서 직접 풀어 보기" 버튼을 누르면 편집기가 열립니다. 코드를 고쳐 가며 실행(Run) 버튼만 누르면 됩니다. 태블릿·PC에서 이용할 수 있고, 폰에서는 코드를 눈으로 따라와도 충분합니다.

1차 시도 — 일단 그대로 쳐 봅니다

첫 목표는 화면에 인사 한 줄을 찍는 것. 화면에 뭔가를 보여 주는 명령이 print라는 것까지만 듣고, 일단 써 보겠습니다.

1차 시도 — 실행하면 에러가 납니다
Print("안녕, 파이썬")

📱 코드 실행(실습)은 태블릿·PC에서 이용할 수 있어요. 모바일에서는 위 코드를 눈으로 따라가며 확인하세요.

실행하면 성공 대신 이런 빨간 글자가 나옵니다.

NameError: name 'Print' is not defined

첫 코드가 첫 에러가 됐습니다. 그런데 이건 사고가 아니라 이 글의 계획입니다. 프로그래밍을 배우는 동안 에러 문장은 매일 만나게 되는데, 첫날 안전한 곳에서 한번 겪어 두면 나중에 당황하지 않습니다.

에러 문장은 혼내는 게 아니라 힌트입니다

방금 그 문장을 번역하면 이렇습니다. "Print라는 이름은 처음 듣는데요." 파이썬이 아는 명령은 소문자 print인데, 우리는 대문자 P로 시작하는 Print를 썼습니다. 파이썬에게 이 둘은 완전히 다른 글자입니다.

한 글자 차이로 갈린 두 화면. 에러 문장 속에 범인의 이름('Print')이 그대로 적혀 있습니다.

여기서 첫 규칙이 나옵니다.

규칙 1 — 파이썬은 대문자와 소문자를 다른 글자로 본다. print, Print, PRINT는 서로 다른 이름이고, 화면 출력 명령은 소문자 print 하나뿐입니다.

고쳐서 다시 — print의 정체

P를 소문자로 바꾸면 통과합니다. 이번엔 통과시키는 김에, print가 정확히 무슨 일을 하는지 그림으로 봐 두겠습니다.

print는 괄호 안의 것을 화면으로 배달하는 명령입니다. 따옴표는 "이건 글자 그대로예요"라는 포장지라서, 화면에는 내용물만 도착합니다.

여기서 규칙 두 개가 더 나옵니다.

규칙 2 — 글자(문자열)는 따옴표로 감싼다. 따옴표를 빼고 print(안녕)이라고 쓰면, 파이썬은 '안녕'을 글자가 아니라 어떤 이름으로 착각하고 또 NameError를 냅니다. 쌍따옴표("안녕")와 홑따옴표('안녕')는 둘 다 되지만, 여는 것과 닫는 것의 짝은 맞아야 합니다.

규칙 3 — # 뒤는 파이썬이 읽지 않는다. 사람만 보라고 남기는 메모(주석)입니다. 코드에 붙이는 포스트잇이라고 생각하면 됩니다.

고친 코드 — 규칙 세 개를 한 번에
# 첫 파이썬 프로그램 (이 줄은 파이썬이 무시합니다)
print("안녕, 파이썬")
print('홑따옴표도 됩니다')

📱 코드 실행(실습)은 태블릿·PC에서 이용할 수 있어요. 모바일에서는 위 코드를 눈으로 따라가며 확인하세요.

완성 — 세 줄 자기소개

이제 오늘의 목표물을 조립합니다. 완성 코드 전문입니다.

완성 — 자기소개 출력 프로그램
# 나의 첫 파이썬 프로그램: 자기소개 카드
print("=" * 30)
print("안녕하세요, 저는 홍길동입니다.")
print("파이썬을 오늘 시작했습니다.")
print("=" * 30)

📱 코드 실행(실습)은 태블릿·PC에서 이용할 수 있어요. 모바일에서는 위 코드를 눈으로 따라가며 확인하세요.

새 얼굴이 하나 있죠. "=" * 30은 등호 글자를 30번 반복하라는 뜻입니다. 파이썬에서 *는 곱하기인데, 글자에 곱하기를 하면 글자가 반복됩니다. 구분선을 그을 때 등호를 30번 칠 필요가 없는 이유입니다. 이름은 여러분 것으로 바꿔서 실행해 보세요 — 위 실행창에서 바로 고칠 수 있습니다.

print()처럼 괄호를 비우면 빈 줄이 하나 찍힌다는 것도 알아 두면, 출력 사이 간격을 띄울 때 씁니다.

여기서 한 발 더

따라 하는 김에 실행창에서 이런 것들을 실험해 보면 오늘 규칙이 손에 붙습니다.

  • 따옴표 하나를 지워 보기 — 어떤 에러 문장이 나오는지 미리 봐 두면 다음에 바로 알아봅니다
  • print("파이썬" * 3) — 글자 반복이 어디까지 되는지
  • print(3 * 7) — 숫자에는 따옴표가 없어도 됩니다. 따옴표 있는 "3"과 뭐가 다른지는 바로 다음 편의 주제입니다

오늘 화면에 찍은 글자들은 실행이 끝나면 사라집니다. 값을 붙잡아 두려면 이름표를 붙인 상자가 필요한데, 그게 다음 편의 변수입니다.
