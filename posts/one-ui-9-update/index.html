원 UI 9 업데이트 일정, S22가 빠지는 이유와 확인법

PANCO_IT2026년 10월 6일 01:02
#원UI9#OneUI9#갤럭시업데이트#소프트웨어업데이트#갤럭시S23#갤럭시S22#생활IT

그림. 업데이트를 기다리는 폰과 누르기 전 확인 칸 네 개 (자체 제작)

원 UI 9 국내 배포는 2026년 9월 16일 갤럭시 S26 시리즈부터 시작했습니다. 삼성전자는 다른 기기에는 차례로 넓혀 간다고만 밝혔습니다. 그래서 S24를 쓰는 사람이 지금 소프트웨어 업데이트를 눌러 보면 "최신 소프트웨어입니다"가 먼저 나올 수 있습니다. 고장이 아닙니다. 아직 그 기종 차례가 오지 않은 것입니다.

2026년 10월 6일에 삼성 뉴스룸, One UI 안내 페이지, 삼성전자서비스 문서를 확인한 범위에서는 기종별 날짜표를 찾지 못했습니다. 삼성 One UI 안내 페이지는 호환 기기 목록과 출시일을 삼성 멤버스 앱에서 확인하라고 적어 두었습니다. 블로그와 커뮤니티에 도는 월별 일정표 상당수는 회원이나 매체가 예상해서 만든 것입니다. 이 글은 그런 표 대신 2026년 10월 6일에 직접 열어 본 삼성 공식 문서 여섯 종을 근거로 씁니다. 뉴스룸 국내·글로벌 보도자료와 One UI 안내 페이지가 먼저입니다. 여기에 삼성전자서비스 고객 지원 문서 두 건과, 기종별 업데이트 약속을 밝힌 2022~2024년 뉴스룸 발표를 더했습니다.

원 UI 9은 어떤 업데이트인가요

원 UI(One UI)는 갤럭시 폰과 태블릿의 화면 구성과 기본 기능을 담당하는 삼성의 소프트웨어입니다. 안드로이드 위에 삼성이 얹은 층이라고 보면 되고, 큰 번호가 바뀌는 업데이트는 해마다 한 번 나옵니다. 원 UI 9은 2026년 7월 공개된 갤럭시 Z 폴드8 울트라, Z 폴드8, Z 플립8에 처음 들어갔습니다. 9월 16일부터는 이미 나와 있는 기기로 내려오기 시작했습니다.

삼성전자 뉴스룸 「삼성전자, One UI 9 공식 버전 업데이트 시작」 첫머리 (출처: news.samsung.com/kr, 2026년 10월 6일 캡처)

새로 들어간 기능은 보도자료 기준으로 크게 세 갈래입니다. 먼저 새 기능입니다. '마이 팬캠'은 영상 속 한 사람을 따라가며 화면 가운데에 맞춰 줍니다. '보증 및 케어'는 보증 기간과 예상 수리비를 설정 안에서 보여 줍니다. 매일 보는 요약 화면인 '나우 브리프'에 카드를 직접 만드는 기능이 붙는 등 기존 기능도 손봤습니다. 그리고 보안 쪽 기능이 늘었는데, 이 부분은 아래에서 따로 봅니다.

원 UI 9의 시작일과 배포 방식 (출처: 삼성전자 뉴스룸·삼성 One UI 안내·삼성전자서비스를 바탕으로 자체 제작)

왜 내 폰에는 아직 안 뜨나요

원 UI 9은 모든 갤럭시에 같은 날 깔리지 않습니다. 삼성 글로벌 뉴스룸 보도자료 각주를 보면, 보도 시점에 공식 원 UI 9이 깔린 기기는 세 가지였습니다. Z 폴드8 울트라, Z 폴드8, Z 플립8입니다. 나머지 기기에는 점차 배포될 예정이라고 했습니다. 삼성 One UI 안내 페이지도 기능과 콘텐츠가 기기 모델에 따라 다를 수 있다고 밝힙니다. 국가와 지역, 이동통신사도 같은 조건으로 적혀 있습니다.

같은 기종이라도 통신사에 따라 받는 날이 다를 수 있다는 뜻입니다. 옆 사람 폰에 먼저 떴다고 내 폰이 고장 난 것은 아닙니다.

차례로 내보내는 데는 안전장치 성격도 있습니다. 2026년 9월 22일에는 스마트싱스 앱으로 업데이트를 받은 삼성 냉장고 일부가 멈췄습니다. 삼성전자는 테스트 과정의 소프트웨어가 잘못 배포됐다고 밝혔습니다. 경위는 냉장고 업데이트 멈춤 글에 있습니다. 한꺼번에 모든 기기에 내보냈다가 문제가 생기면 되돌리기 어렵습니다. 그래서 먼저 나간 기기에서 문제가 없는지 보고 다음 기종으로 넘어가는 방식이 흔히 쓰입니다. 이 설명은 업계의 일반적인 배포 방식에 대한 제 판단입니다. 삼성이 원 UI 9 배포 순서를 이렇게 정했다고 밝힌 적은 없습니다.

내 갤럭시가 원 UI 9을 받는지 셈하는 법

삼성은 기종을 내놓을 때마다 큰 번호 업데이트를 몇 번 해 줄지 약속해 왔습니다. 공식 날짜표가 없어도 이 약속을 알면 내 폰이 원 UI 9 대상인지는 셈해 볼 수 있습니다.

갤럭시 S23 시리즈5.1OS 업그레이드 4세대, 보안 업데이트 5년 (2023년 2월 발표)원 UI 9

S22는 출시 때 원 UI 4.1이었습니다. 여기서 5, 6, 7, 8로 네 번 올라가면 약속한 4세대를 다 씁니다. S23은 5.1로 나왔으니 6, 7, 8, 9까지가 네 번입니다. S23에게 원 UI 9은 약속 범위 안의 마지막 큰 업데이트입니다. S22는 원 UI 8에서 멈춥니다. 2026년 10월 6일 기준으로 삼성이 S22용 원 UI 9을 내놓겠다고 발표한 자료는 찾지 못했습니다.

출시 때 버전에서 약속한 횟수만큼 칸을 채운 그림 (출처: 삼성 뉴스룸 2022·2023·2024년 발표를 바탕으로 자체 제작)

이 셈이 맞는지 확인할 단서가 원 UI 9 보도자료 안에 하나 더 있습니다. 글로벌 보도자료의 일곱 번째 각주입니다. 원 UI 9의 새 기능인 '개인정보 보호 알림(Privacy Alerts)'을 지원하는 기기가 나열돼 있습니다. S26, S25, S24, S23 계열과 S23 FE, Z 폴드5·플립5부터 폴드8까지가 들어 있습니다. S22는 없습니다.

삼성 글로벌 뉴스룸 원 UI 9 보도자료 각주 1번과 7번 (출처: news.samsung.com/global, 2026년 10월 6일 캡처)

이 각주는 기능 하나의 지원 목록이지 업데이트 대상 목록이 아닙니다. 그래도 S23과 Z 폴드5·플립5가 원 UI 9 기능 목록에 이름을 올렸다는 점은 앞의 셈과 맞아떨어집니다. A 시리즈처럼 여기 없는 기종도 출시 때 버전과 약속 횟수로 같은 셈을 해 볼 수 있습니다. 최종 확인은 삼성 멤버스 앱 공지로 합니다.

S22·S23을 계속 써도 되나요

큰 번호 업데이트가 끝났다고 폰이 바로 위험해지지는 않습니다. 삼성은 OS 업그레이드와 보안 업데이트를 따로 약속합니다. S23은 OS 업그레이드 4세대와 별개로 보안 업데이트 5년을 약속받았습니다. 2023년 2월에 나온 기종이니 약속대로라면 원 UI 9 이후에도 보안 패치는 한동안 계속 들어옵니다.

S22도 2023년 2월 S23 보도자료 각주에서 5년 보안 업데이트 대상에 함께 올라 있습니다. 새 기능은 원 UI 8에서 멈추지만 보안 패치는 그 뒤로도 이어진다는 뜻입니다. 보안 패치가 언제까지 오는지는 보안 업데이트 끝난 폰 글에서 확인하는 법을 다뤘습니다. 보안 업데이트만 따로 받으려면 경로가 다릅니다. 설정에서 '보안 및 개인정보 보호', '업데이트', '보안 업데이트' 순서로 들어갑니다. 거기서 '업데이트 확인'을 누릅니다.

S23 사용자에게는 원 UI 9이 마지막 큰 변화입니다. S22 사용자는 원 UI 9 기능을 기다리지 않아도 됩니다. 둘 다 보안 패치가 들어오는 동안은 계속 써도 됩니다.

업데이트를 누르기 전에 볼 것

삼성전자서비스의 「소프트웨어 업데이트를 하고 싶어요」 문서는 업데이트 전에 지킬 것을 짧게 적어 두었습니다. 그중 가장 먼저 읽을 문장은 되돌릴 수 없다는 안내입니다. 기기를 최신 소프트웨어로 올린 뒤에는 강화된 보안 정책 때문에 이전 펌웨어 버전으로 돌아갈 수 없습니다.

삼성전자서비스 「소프트웨어 업데이트를 하고 싶어요」 주의 문구 (출처: samsungsvc.co.kr, 2026년 10월 6일 캡처)

그다음은 배터리입니다. 업데이트 전에 배터리가 20% 이상인지 확인하라고 되어 있습니다. 진행 중에는 USB 케이블을 빼거나 기기를 쓰지 말라는 안내도 있습니다. 설치 중에 폰이 여러 번 꺼졌다 켜질 수 있는데, 이것도 정상 과정으로 적혀 있습니다.

다만 갤럭시 S25와 일부 모델부터는 업데이트 방식이 바뀌었습니다. 근거는 삼성전자서비스의 다른 문서 「갤럭시, 휴대전화(소프트웨어) 업데이트 알림이 발생합니다」입니다. 이 기종들은 다운로드와 설치, 인증 단계에서도 폰을 쓸 수 있습니다. 인증은 업데이트가 제대로 설치됐는지 확인하는 단계입니다. 예전 방식은 설치 단계부터 폰을 쓸 수 없었습니다.

삼성전자서비스 「소프트웨어 업데이트 데이터 사용 정책 안내」 (출처: samsungsvc.co.kr, 2026년 10월 6일 캡처)

데이터 요금도 봅니다. 같은 문서는 모바일 데이터로 내려받으면 추가 요금이 붙을 수 있다며 와이파이를 권합니다. 업데이트용 무료 데이터는 통신사 정책에 따라 다릅니다. 알뜰폰은 더 조심해야 합니다. 쓰는 망의 통신사 정책과 상관없이 별도 정책으로 데이터 비용이 청구될 수 있다고 적혀 있습니다. 알뜰폰을 쓰는 부모님 폰이라면 집 와이파이에 연결한 뒤 진행하면 됩니다.

누르기 전에 볼 네 가지 (출처: 삼성전자서비스 안내를 바탕으로 자체 제작, "급하지 않으면 미뤄도 됨"은 필자 판단)

삼성 안내문에 백업 이야기는 없습니다. 업데이트로 사진이 지워진다는 공식 안내도 없습니다. 그래도 되돌릴 수 없는 업데이트라 저는 미리 옮겨 두기를 권합니다. 사진과 연락처, 카카오톡 대화처럼 잃으면 곤란한 것들입니다. 설치 중에 전원이 꺼지는 경우에도 백업이 있으면 다시 살릴 수 있습니다. 업무용 앱이나 은행 앱이 새 버전에서 바로 돌아가는지 걱정된다면 며칠 미뤄도 됩니다. 급한 보안 패치가 아니라면 큰 번호 업데이트를 바로 받을 의무는 없습니다.

폰에서 받는 법과 PC로 받는 법

받는 길은 두 가지입니다. 대부분은 폰에서 바로 받습니다. 설정을 열고 '소프트웨어 업데이트'로 들어가 '다운로드 및 설치'를 누릅니다. 업데이트가 있으면 내려받기와 설치가 진행되고, 끝나면 '지금 다시 시작'을 누릅니다. 아직 차례가 아니면 최신 소프트웨어라는 문구가 나옵니다. 알림창에 '휴대전화 업데이트'가 떠 있다면 그 알림을 눌러도 같은 화면으로 갑니다.

PC가 있다면 삼성 Smart Switch 프로그램으로도 받을 수 있습니다. PC에서 Smart Switch를 실행하고 폰과 함께 받은 USB 케이블로 연결합니다. 폰에 USB 연결 방식을 묻는 창이 뜨면 파일 전송을 허용합니다. 업데이트가 있으면 Smart Switch 화면에 안내가 나오고, 업데이트를 선택해 진행하면 됩니다. 폰 화면을 오래 보기 어려운 분이라면 PC 쪽이 글자가 커서 따라가기 쉽습니다.

폰과 PC에서 업데이트를 받는 순서 (출처: 삼성전자서비스 안내를 바탕으로 자체 제작)

자동 다운로드 설정도 알아 두면 좋습니다. '소프트웨어 업데이트' 안의 '자동 다운로드'에서 언제 미리 내려받을지 고를 수 있습니다. '안 함'으로 바꿔 두어도 예외가 있습니다. 삼성전자서비스 문서에 따르면 안전과 보안상 중요한 업데이트는 모바일 데이터로 자동 다운로드될 수 있습니다. 큰 번호 업데이트를 미뤄 둔 사람도 보안 패치는 계속 받게 됩니다.

업데이트 뒤 먼저 켜 볼 보안 기능

원 UI 9에서 4060 사용자에게 가장 쓸모 있는 변화는 보안 쪽입니다. 삼성전자 뉴스룸 국내 보도자료가 소개한 기능 세 가지를 차례로 봅니다.

첫째는 '시큐리티 브리프'입니다. 나우 브리프 안에 들어가는 기능입니다. 악성 앱, 출처를 알 수 없는 앱, 불필요한 권한 사용을 주기적으로 요약해 보여 줍니다. 항목을 누르면 필요한 조치로 바로 이어집니다. 문자 링크로 앱을 깔게 만드는 스미싱에 대비할 때 쓸 수 있습니다. 모르는 사이에 깔린 앱이 이 요약에 잡히기 때문입니다. 스미싱 수법은 스미싱이란 글에 따로 정리했습니다.

둘째는 기기 안에서 도는 AI로 개인정보 위험을 찾는 '개인정보 보호 알림'입니다. 앱이 불필요하게 권한에 접근하려는 시도를 미리 알려 줍니다. 보도자료는 일부 제품에서만 지원하고 모든 위험을 감지하지는 못할 수 있다고 덧붙였습니다.

셋째는 통화 중 상대 목소리가 AI로 변조됐는지 분석하는 기능입니다. 변조나 조작 징후가 보이면 통화 화면 팝업, 알림음, 진동으로 경고합니다. 보도자료 각주에 따르면 이 기능은 한국 지역에서만 지원하고 해외에서 산 제품에서는 쓰지 못할 수 있습니다. 가족 목소리를 흉내 낸 사기는 딥페이크 사기 정리에서 따로 다뤘습니다. 새 기능 위치는 설정 맨 아래의 사용 설명서 메뉴에서 찾을 수 있습니다. 삼성 미국 고객지원 문서가 그 안의 원 UI 9 새 기능 안내를 보라고 적어 두었습니다. 메뉴 이름은 기종에 따라 조금씩 다릅니다.

원 UI 9에서 늘어난 보안 기능 세 가지 (출처: 삼성전자 뉴스룸 2026년 9월 17일 보도자료를 바탕으로 자체 제작)

보안 기능은 아니지만 함께 볼 만한 것이 '보증 및 케어' 메뉴입니다. 삼성 계정에 연결된 기기의 보증 기간, 자가 진단, 예상 수리비, 서비스 센터 예약을 설정 안에서 처리합니다. 업데이트 뒤 배터리가 빨리 닳는 것 같다면 여기서 자가 진단부터 돌려 봅니다. 그래도 이상하면 서비스 센터를 예약합니다. 삼성전자서비스 고객센터 번호는 1588-3366입니다.
