while이 뭔가요 — 조건이 참인 동안

정의부터 세웁니다. 파이썬 공식 자습서(2026년 9월 9일 기준 3.13판)는 while을 이렇게 정의합니다. 조건이 참인 동안 블록을 되풀이한다. for가 "이 묶음을 하나씩 다 돌 때까지"라면, while은 "이 조건이 참인 한 계속"입니다. 몇 번 돌지는 미리 정해져 있지 않고, 조건이 거짓이 되는 순간이 곧 끝입니다.

한 바퀴의 순서는 언제나 같습니다. 조건을 검사한다, 참이면 들여쓴 블록을 한 번 실행한다, 다시 조건으로 돌아간다. 거짓이면 블록을 건너뛰고 while 아래 줄로 내려갑니다. 그래서 while 문장에는 눈에 보이지 않는 세 부품이 있습니다. 조건에 쓰이는 값의 처음 값, 매 바퀴 검사하는 조건, 그리고 블록 안에서 그 값을 바꾸는 갱신. 셋 중 하나가 빠지면 반복은 시작하지 못하거나 끝나지 못합니다.

한 바퀴는 검사, 실행, 갱신 순서입니다. count가 0에서 5로 자라며 다섯 번 돌고, 5가 되는 순간 조건이 거짓이라 끝으로 나옵니다. 점선 자리가 오늘 사건의 현장입니다.

증상 — 0이 멈추지 않습니다

첫 단서는 찍힌 값입니다. 0만 나옵니다. 1이나 2가 한 번도 안 보입니다. 반복은 돌고 있는데 count가 자라지 않는다는 뜻입니다.

터미널에 0만 쌓입니다. 1이 한 번도 안 나온다는 사실이 범인을 가리키는 첫 단서입니다.

용의자 하나 — 조건이 틀렸나

count < 5를 봅니다. 0은 5보다 작으니 참, 그래서 블록이 실행됩니다. 여기까지는 맞습니다. 만약 count > 5라고 썼다면 처음부터 거짓이라 한 줄도 안 찍혔을 것이고, count <= 5라면 0부터 5까지 여섯 줄이 나왔을 것입니다. 지금 증상은 둘 다 아닙니다. 조건은 무죄입니다.

조건식만 따로 확인하기 — 참인지 거짓인지
count = 0
print(count < 5)
print(count > 5)
count = 5
print(count < 5)

용의자 둘 — 들여쓰기가 잘못됐나

6편에서 들여쓰기가 문법이었습니다. print(count)는 네 칸 안쪽에 있으니 블록 안이고, print("끝")은 왼쪽 끝에 붙어 있으니 반복이 끝난 뒤 한 번 실행되는 줄입니다. 블록 범위도 맞습니다. 들여쓰기도 무죄.

진범 — 조건에 쓰인 값이 한 번도 바뀌지 않았습니다

남은 것은 하나입니다. count는 0으로 시작했고, 블록 안에서 count를 건드리는 줄이 없습니다. 검사할 때마다 count는 여전히 0이고, 0은 언제나 5보다 작습니다. 조건이 거짓이 될 길이 없으니 끝도 없습니다. 이것이 무한 루프이고, 원인은 빠진 갱신 한 줄입니다.

갱신 한 줄을 넣은 코드 — 다섯 번 돌고 멈춥니다
count = 0
while count < 5:
  print(count)
  count += 1
print("끝, count =", count)

count += 1은 count = count + 1을 줄여 쓴 것입니다. 한 바퀴마다 1씩 커져 0, 1, 2, 3, 4를 찍고, 5가 되면 count < 5가 거짓이라 반복이 끝납니다. 마지막 줄이 count = 5인 점도 눈여겨볼 대목입니다. 반복이 끝난 뒤에도 그 값은 남아 있습니다.

for가 이 사건을 겪지 않는 이유도 여기서 보입니다. for는 다음 값을 꺼내는 일과 끝을 판단하는 일을 파이썬이 대신합니다. while은 둘 다 내 몫입니다. 자유로운 대신 책임도 따라옵니다.

재발 방지 — 세 줄 점검과 안전장치

while을 쓸 때마다 세 줄을 눈으로 확인하는 습관이 가장 싸게 먹힙니다. 처음 값이 있는가, 조건이 언젠가 거짓이 되는가, 블록 안에서 그 값이 바뀌는가. 특히 셋째 줄은 블록 맨 아래에 두는 편이 눈에 잘 띕니다.

값이 바뀌기는 하는데 조건을 영영 못 만나는 경우도 있습니다. 1에서 시작해 2배씩 키우며 100이 되기를 기다리면, 64 다음이 128이라 100을 그냥 지나칩니다. 이럴 때는 횟수 상한을 하나 더 두면 프로그램이 스스로 멈춥니다.

안전장치 — 20번 넘게 돌면 강제로 끝냅니다
x = 1
steps = 0
while x != 100:
  x *= 2
  steps += 1
  if steps > 20:
      print("20번 넘게 돌아도 못 끝냈습니다. x =", x)
      break

📱 코드 실행(실습)은 태블릿·PC에서 이용할 수 있어요. 모바일에서는 위 코드를 눈으로 따라가며 확인하세요.

20번 넘게 돌아도 못 끝냈습니다. x = 2097152

x != 100은 "100이 아닌 동안"이라는 뜻인데 x가 100이 되는 일은 없습니다. steps가 21이 되는 순간 break가 반복을 끊어 줍니다. 저는 조건이 조금이라도 미덥지 않으면 이 상한을 습관처럼 넣습니다. 나중에 지워도 되고, 남겨 두어도 해가 없습니다.

일부러 멈추지 않게 만들고 break로 나갑니다

무한 루프가 항상 사고는 아닙니다. 메뉴를 보여 주고 사용자가 종료를 누를 때까지 기다리는 프로그램은 애초에 끝을 조건으로 쓰기 어렵습니다. 그럴 때 조건을 True로 고정해 "일단 계속 돈다"로 시작하고, 나갈 지점에서 break를 씁니다.

while True와 break — 0을 누를 때까지 도는 메뉴
inputs = ["1", "1", "9", "0"]   # 사용자가 누른 순서를 미리 적어 둔 것입니다
i = 0
total = 0
while True:
  cmd = inputs[i]
  i += 1
  if cmd == "0":
      print("종료, 누른 횟수", total)
      break
  if cmd not in ("1", "2"):
      print("없는 메뉴:", cmd)
      continue
  total += 1
  print("메뉴", cmd, "실행")

메뉴 1 실행
메뉴 1 실행
없는 메뉴: 9
종료, 누른 횟수 2

inputs는 4편의 input()을 흉내 낸 것입니다. 실행창에서 매번 입력을 받기 어려워 누른 순서를 리스트에 적어 두었습니다. "0"을 만나면 break가 반복을 끝내고, "9"처럼 없는 메뉴는 continue가 아래 두 줄을 건너뛰어 다음 입력으로 넘어갑니다. break와 continue가 한 블록에 같이 있는 모습이 실제 프로그램의 흔한 생김새입니다.

트랙 한 바퀴가 블록 한 번입니다. break는 트랙을 아예 벗어나고, continue는 남은 구간을 건너뛰어 출발선으로 돌아가 다음 바퀴 검사를 받습니다.

비밀번호를 세 번까지만 받는 프로그램도 같은 구조입니다. 여기에는 while의 짝인 else가 하나 더 붙습니다.

세 번 안에 맞히면 break, 다 틀리면 else
answer = "1234"
attempts = ["1111", "2222", "1234"]
tries = 0
while tries < 3:
  guess = attempts[tries]
  tries += 1
  if guess == answer:
      print(tries, "번째에 맞았습니다")
      break
  print(tries, "번째 실패:", guess)
else:
  print("3번 모두 실패, 잠깁니다")

📱 코드 실행(실습)은 태블릿·PC에서 이용할 수 있어요. 모바일에서는 위 코드를 눈으로 따라가며 확인하세요.

1 번째 실패: 1111
2 번째 실패: 2222
3 번째에 맞았습니다

else는 반복이 break 없이 조건으로 끝났을 때만 실행됩니다. 위 실행은 세 번째에 맞아 break로 나왔으니 else가 돌지 않았습니다. attempts의 마지막 값을 "9999"로 바꾸면 세 번 다 실패하고 잠깁니다 문장이 나옵니다. if의 else와 이름은 같지만 뜻이 달라 처음엔 낯선데, "끝까지 다 돌았을 때"로 읽으면 됩니다.

continue — 이번 바퀴만 건너뛰기

continue만 따로 봅니다. 1부터 10까지 가는 동안 짝수는 찍지 않는 코드입니다.

짝수는 건너뛰고 홀수만 — 갱신 줄의 위치를 보세요
n = 0
while n < 10:
  n += 1
  if n % 2 == 0:
      continue
  print(n, end=" ")
print()

📱 코드 실행(실습)은 태블릿·PC에서 이용할 수 있어요. 모바일에서는 위 코드를 눈으로 따라가며 확인하세요.

1 3 5 7 9

갱신 n += 1이 블록 맨 위에 있습니다. continue는 아래 줄을 건너뛰기 때문에, 갱신을 continue 뒤에 두면 짝수에서 n이 안 자라고 그 자리에 머무는 무한 루프가 됩니다. continue가 있는 블록에서 갱신 줄은 continue보다 위에 둔다. 이 한 줄이 오늘 사건의 두 번째 재발 방지 수칙입니다.

for와 while, 어느 쪽을 쓰나

같은 일을 둘 다로 쓸 수 있습니다. 세 번 인사하는 코드입니다.

같은 일, 두 문법
for k in range(3):
  print("for", k)
k = 0
while k < 3:
  print("while", k)
  k += 1

돌 횟수를 미리 알거나 돌 묶음이 있으면 for가 짧고 안전합니다. 처음 값과 갱신을 파이썬이 맡아 주니 빠뜨릴 줄이 없습니다. 반대로 몇 번인지 모르고 조건이 끝을 정하는 일은 while의 자리입니다. 잔액이 남아 있는 동안 커피를 사는 코드는 몇 잔이 될지 미리 알 수 없습니다.

잔액이 커피 값 이상인 동안 — 몇 잔인지는 돌아 보면 압니다
balance = 10000
price = 3000
cups = 0
while balance >= price:
  balance -= price
  cups += 1
print(cups, "잔,", balance, "원 남음")
