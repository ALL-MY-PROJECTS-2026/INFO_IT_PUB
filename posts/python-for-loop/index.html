print를 여섯 줄 쓰면 지금 당장은 됩니다. 물건이 여섯 개가 되면 한 줄을 더 쓰고, 값이 바뀌면 여섯 줄을 다 고칩니다. 물건이 몇 개든 같은 코드로 끝내려면 "하나씩 꺼내서 같은 일을 반복하는" 문법이 필요합니다. 그것이 for 반복문입니다.

for는 칸을 하나씩 꺼내 주는 문법입니다

파이썬 공식 자습서는 for 문을 이렇게 정의합니다. 리스트나 문자열 같은 시퀀스의 항목들을, 그 시퀀스에 들어 있는 순서대로 하나씩 꺼내 처리하는 문장. 다른 언어의 for가 "몇 번 돌아라"에 가깝다면, 파이썬의 for는 "이 묶음에서 하나씩 꺼내라"에 가깝습니다. 그래서 횟수를 세는 변수 없이 리스트를 통째로 넘기면 됩니다.

쓰는 순간은 같은 일을 값만 바꿔 여러 번 할 때입니다. 장바구니 값 더하기, 점수 열 개 평균 내기, 문장의 글자를 한 자씩 검사하기. 개수가 몇이든 코드는 한 덩어리입니다.

for 한 줄은 네 조각입니다. 꺼낼 묶음, 담을 이름, 그리고 콜론 뒤에 들여쓴 블록. 들여쓰기가 없는 줄은 반복이 다 끝난 뒤 한 번만 실행됩니다.

첫 줄이 9에서 끝납니다. range(1, 10)은 "1부터 10까지"가 아니라 **"1부터 시작해 10 앞에서 멈춘다"**입니다. 7편 슬라이싱의 cart[1:4]가 4번 칸을 빼고 세 칸만 주던 것과 같은 규칙입니다. 공식 문서의 표현을 빌리면 끝값은 만들어지는 수열에 포함되지 않고, range(10)은 길이 10인 리스트의 올바른 인덱스 열 개를 만듭니다. 0부터 9까지. 리스트 번호가 0에서 시작하니 끝을 빼야 개수가 딱 맞습니다.

range(1, 11)이 만드는 수는 1부터 10까지 열 개입니다. 끝에 적은 11은 들어오지 않습니다. 숫자 하나면 0부터, 셋이면 세 번째가 건너뛰는 간격입니다.

그러니 10까지 더하려면 끝에 11을 적습니다.

range가 리스트를 미리 만들어 두는 것은 아닙니다. print(range(10))을 하면 [0, 1, …]이 아니라 range(0, 10)이라고만 나옵니다. 돌 때마다 다음 수를 하나씩 내주는 물건이라 백만까지 돌려도 백만 칸짜리 리스트가 생기지 않습니다. 그래서 위에서 눈으로 보려고 list(range(…))로 한 번 감쌌습니다.

이름과 가격을 나란히 — range(len(…))

영수증에는 물건 이름과 값이 한 줄에 같이 찍혀야 합니다. 리스트가 둘인데 for는 한 번에 하나만 돕니다. 이럴 때 range가 다시 나옵니다. 두 리스트의 칸 번호를 돌면 같은 번호로 양쪽을 꺼낼 수 있습니다.

칸 번호로 두 리스트를 같이 읽기
cart = ["사과", "우유", "계란", "빵", "커피"]
prices = [3000, 2500, 6000, 4200, 8900]
for i in range(len(cart)):
  print(i, cart[i], prices[i])

len(cart)가 5이니 range(5), 곧 0부터 4까지. 칸이 다섯이면 마지막 번호는 4라던 7편 규칙이 여기서 range의 끝 빠짐과 정확히 맞물립니다. 끝을 빼기 때문에 range(len(cart))는 언제나 리스트의 번호와 같은 범위가 됩니다. 이 궁합 덕에 range(len(리스트))는 파이썬 코드에서 관용구처럼 쓰입니다. 공식 문서는 번호와 값이 같이 필요할 때 enumerate가 더 편하다고 덧붙이는데, 그 함수는 다음 시즌에서 다룹니다.

세 번째 시도 — 돌면서 지웠더니 계란이 남았습니다

계산을 마친 물건을 장바구니에서 빼는 코드를 붙여 봅니다. 우유와 계란은 이미 샀다고 치고 지웁니다.

돌면서 지우기 — 결과를 예상하고 실행해 보세요
cart = ["사과", "우유", "계란", "빵", "커피"]
for item in cart:
  if item == "우유" or item == "계란":
      cart.remove(item)
print(cart)

우유는 지워졌는데 계란이 남았습니다. 에러도 없습니다. for는 리스트를 칸 번호 순서로 읽습니다. 둘째 바퀴에 1번 칸 우유를 지우면 뒤에 있던 계란이 1번 칸으로 당겨 오는데, for는 다음 바퀴에 2번 칸을 봅니다. 그 자리에는 빵이 와 있습니다. 계란은 검사를 받지 못한 채 지나갑니다.

돌고 있는 리스트를 지우면 뒤 칸이 앞으로 당겨지고, for는 다음 번호로 넘어갑니다. 당겨온 값은 검사를 건너뜁니다. 사본을 돌거나 새 리스트를 만들면 됩니다.

공식 문서는 이 상황을 두고 컬렉션을 돌면서 같은 컬렉션을 고치는 코드는 올바르게 만들기 어렵다고 적고, 사본을 돌거나 새 컬렉션을 만들라고 권합니다. 둘 다 7편에서 본 문법입니다.

사본을 돌기 — cart[:]가 복사본이었습니다
cart = ["사과", "우유", "계란", "빵", "커피"]
for item in cart[:]:
  if item == "우유" or item == "계란":
      cart.remove(item)
print(cart)

cart = ["사과", "우유", "계란", "빵", "커피"]
keep = []
for item in cart:
  if item != "우유" and item != "계란":
      keep.append(item)
print(keep)

첫 방법은 cart[:]로 만든 복사본을 돌면서 원본을 지웁니다. 복사본은 줄어들지 않으니 다섯 바퀴가 온전히 돕니다. 둘째 방법은 남길 것만 새 리스트에 담습니다. 저는 둘째 쪽을 더 자주 씁니다. 지우는 코드보다 남기는 코드가 읽을 때 뜻이 분명해서입니다.

완성 — 영수증 열 줄

세 번의 시도를 합치면 처음에 보여 드린 영수증이 됩니다. 이름과 값을 같이 읽어야 하니 range(len(cart)), 합계는 반복 밖에서 0, 계산이 끝난 뒤 장바구니는 새 리스트로.

완성 코드 — 값을 바꿔 가며 출력을 예상해 보세요
cart = ["사과", "우유", "계란", "빵", "커피"]
prices = [3000, 2500, 6000, 4200, 8900]

total = 0                          # 반복 밖에서 시작
for i in range(len(cart)):         # 0부터 4까지 — 끝 5는 빠집니다
  total += prices[i]             # 한 바퀴에 한 번
  print(cart[i], prices[i], "누적", total)
print("합계", total)

paid = []                          # 새 리스트에 담는 쪽
for item in cart:
  if item != "우유":
      paid.append(item)
print(paid)

물건이 여섯 개가 되면 두 리스트에 한 칸씩만 붙이면 됩니다. 코드는 한 글자도 안 바뀝니다. 그것이 반복문을 쓰는 이유입니다.

조금 더 — 문자열도 돌고, 거꾸로도 돕니다

in 뒤에 올 수 있는 것은 리스트만이 아닙니다. 문자열을 놓으면 글자가 한 자씩 나옵니다. range의 세 번째 자리에 음수를 주면 거꾸로 셉니다.

문자열 한 자씩, 그리고 거꾸로 세기
for ch in "파이썬":
  print(ch, end=" ")
print()
for n in range(10, 0, -2):
  print(n, end=" ")
print()
print(sum(range(1, 11)))
